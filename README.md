# Action-Cloud

Sponsor site for Action Cloud Bucharest. Plain HTML and CSS, no build step: open `index.html`, or serve the folder with any static host.

Before going live:

- Replace the placeholder email in the contact section of `index.html` (search for `REPLACE-WITH-REAL-EMAIL`).
- Remove `<meta name="robots" content="noindex">` from `index.html`.

Fonts (Big Shoulders Stencil, Barlow) are self-hosted under the SIL Open Font License.
